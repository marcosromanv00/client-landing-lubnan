# Lubnan: Landing Page Premium

Experiencia web de lujo para el restaurante Lubnan, centrada en la estética premium y la optimización de conversiones.

## 🚀 Overview
Una landing page diseñada para reflejar la sofisticación de Lubnan, combinando un diseño visual impresionante con un rendimiento técnico excepcional y flujos de reserva optimizados.

## ✨ Key Achievements
- **Core Web Vitals 100**: Optimización extrema para lograr puntuaciones perfectas en rendimiento, SEO y accesibilidad.
- **Diseño Premium**: Implementación de Glassmorphism y animaciones fluidas con Framer Motion.
- **Conversión de Reservas**: Integración fluida con sistemas de reserva para maximizar la captación de clientes online.

## 🛠️ Technologies
- TypeScript / Next.js
- Tailwind CSS
- Framer Motion
- Vercel (Deployment & Edge)

## 📦 Features
- Menú digital interactivo.
- Galería de imágenes optimizada.
- Sistema de reservas integrado.
